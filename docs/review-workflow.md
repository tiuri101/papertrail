# Review Workflow

Papertrail uses six shared project states: draft, duplicate review, title/abstract screening, full-text retrieval and screening, extraction and quality assessment, and completed.

Automatic transitions depend on authoritative workflow records. Duplicate suggestions must all be resolved before screening. Screening requires all reviewer slots and conflict resolutions. Full-text work distinguishes reports not retrieved from eligibility exclusions. Completion requires extraction and any enabled quality assessment for every finally included publication.
