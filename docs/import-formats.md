# Import Formats

Papertrail accepts CSV, XLSX, RIS, and BibTeX files. It includes source adapters for common ScienceDirect, IEEE Xplore, ACM Digital Library, and SpringerLink exports, plus generic mappings.

The preferred normalized fields are title, authors, abstract, year, venue, publication type, DOI, URL, keywords, ISBN, ISSN, PubMed identifier, and arXiv identifier. Title is required for a valid imported record. Unknown tabular layouts can be previewed and mapped before import. Original rows are retained unchanged for provenance.
